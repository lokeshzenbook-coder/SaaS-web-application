Everything you need to launch

🔐 Authentication

Register, login, and logout with hashed passwords and httpOnly JWT cookies. No third-party auth needed.

💳 Subscriptions

Free, Pro, and Enterprise plans with monthly pricing. Simulated checkout that you can swap for Stripe.

📊 Usage quotas

Per-month call counters enforce your plan limits and return friendly 429 responses when exhausted.

🔑 API keys

Every account gets a scoped API key to hit your product API with per-plan rate limits.

🛡️ Security first

Security headers, input validation, rate limiting, and no plaintext passwords anywhere.

🧪 Tested

An end-to-end API test suite runs with the built-in Node test runner — `npm test`.
